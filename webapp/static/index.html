    Settings

    Paths are on this machine. Nothing works until they point at real folders — they are deliberately not shipped.

    The funnel engine reads both reports as one month and writes the four insights, the summary and the SMS from the figures rather than from each other. It changes what a dealership reads and nothing else about how the month is produced, so a month can be run on each and read side by side before committing.

    AI assisted is the funnel engine plus a rewrite: the figures and the findings are still calculated here, and a model is asked only to say them better. Anything it returns is checked back against those figures and thrown away whole if a number appears that nobody calculated, so a month never depends on it working. Needs a key in a .env file beside the app — copy .env.example to .env and fill it in.

    Builds the four-page report for each dealership from the workbook's history tab, and shows it in the report pane on step 1. Because it reads the history rather than the workbook's own report tabs, it can be produced for any month the workbook covers. Needs Chromium; without it the month still runs and the pane says so.
